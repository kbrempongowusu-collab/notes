## Week 1 - History
- Writing systems have changed over time.
- One writing system can be used by different languages.

## Week 2 - Bits and Bytes
- Computers use bits to represent information.
- A byte contains 8 bits.

## Week 3 - Text Encoding
- ASCII represents characters using numbers.
- Unicode supports characters from many languages.

## Week 4 - Numbers
- Binary uses only 0 and 1.
- Hexadecimal uses 16 symbols.

## Week 5 - Command Line
- Commands help us work with files and folders.
- The command line allows us to interact with a computer.
